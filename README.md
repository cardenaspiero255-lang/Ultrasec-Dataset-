# UltraSec V7.0 — Public project registry

Repositorio público de documentación, **no de código propietario**, de UltraSec V7.0.

La documentación del proyecto y el aviso de derechos reservados están en [ultrasec-v7/](ultrasec-v7/README.md).

Los datos, el motor de análisis, los generadores y los desafíos reservados se gestionan por separado y **no se publican aquí**.

Los siete checks automáticos validan únicamente las políticas de publicación y la integridad documental. **No son una certificación de seguridad ni evidencia de que el dataset tenga un precio determinado.**
